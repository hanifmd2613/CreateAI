# 24 — External Integrations

## 1. Supported Integration Providers

1. **Google Gemini API**:
   - Model: `gemini-1.5-flash`
   - Purpose: Conversational marketplace queries, prompt parameter refinement, natural language summaries.
2. **Groq Cloud API**:
   - Model: `llama-3.3-70b-versatile`
   - Purpose: Ultra-low-latency structured brief parameter extraction and keyframe targeting.
3. **Firebase Cloud Ecosystem**:
   - Authentication (Email/Password, Google OAuth).
   - Cloud Firestore (Dual-write persistence mirror).
   - Firebase Storage (Media asset binary hosting).
4. **Local / Sandboxed Fallback Engine**:
   - Pure TypeScript deterministic brief parser and media validator running with zero external network dependencies.
