# 31 — Changelog

## [2.0.0] - Round 2 Release (2026-10-24)

### Added
- **Intelligent Creator Matching Engine (Module A)**: 6-factor normalized scoring ($w_i = [0.25, 0.20, 0.15, 0.20, 0.10, 0.10]$), deterministic ranking, and empirical ground-truth explanations.
- **Engagement Lifecycle State Machine (Module B)**: 19 discrete states with role-based transition guards, prerequisite checks, and audit trails.
- **Immutable Revision & Draft History (Module C)**: Multi-version draft tracking (V1, V2...), non-destructive point-in-time storage, and version-anchored feedback with resolution statuses.
- **Licensing Compatibility Gate (Module D)**: Decoupled IP evaluation engine checking usage types, territory, duration, paid ad rights, and exclusivity.
- **Auto-Shortlist Agent (Bonus A)**: Autonomous proposal engine with hard constraint filtering, human-in-the-loop review, and complete decision logging.
- **Actual File Delivery Checker Engine (Bonus B)**: Real file binary inspection validating image dimensions and ISO-BMFF MP4 video container headers (duration, resolution, aspect ratio, decodability).
- **Comprehensive Engagement Workspace UI**: Unified workspace for brands and creators with timeline tracking, media inspectors, and feedback resolution.
- **Comprehensive Automated Test Suite**: Unit, integration, and E2E acceptance tests verifying all 18 mandatory challenge scenarios.

### Preserved & Enhanced
- All Round 1 creator profiles, portfolios, workflow steps, prompts, and briefs.
- AI Brief Co-Pilot with multi-engine LLM abstraction (Groq, Gemini, deterministic fallback).
- Dark/light theme engine, custom viewfinder cursor, and spotlight effects.
